# Glyph for iPhone and iPad Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the existing `Glyph` target build and run on iOS 17+ (iPhone and iPad), with the Mac app unchanged, and upload both platforms to TestFlight.

**Architecture:** One multiplatform XcodeGen target. CoreGraphics canvas drawing moves into a shared `CanvasRenderer`, hosted by the existing `NSView` on the Mac and by a new `UIView` on iOS. AppKit-only pieces sit behind `#if os(macOS)`. iOS gets its own toolbar, an `.inspector` panel, PhotosPicker, the camera, `fileImporter`/`fileExporter` and `ShareLink`.

**Tech Stack:** Swift 6, SwiftUI, UIKit/AppKit hosts, XcodeGen, `xcodebuild`, `xcrun simctl`.

**Spec:** `docs/superpowers/specs/2026-11-19-ios-app-design.md`

## Global Constraints

- iOS deployment target is `17.0`; macOS stays `14.0`.
- Bundle ID `co.jadam.glyph`, team `9247LFQ5JV`. Only `scripts/testflight.sh` signs with the team.
- `CODE_SIGN_ENTITLEMENTS[sdk=macosx*]: Glyph.entitlements` (the sandbox). `[sdk=iphoneos*]` uses `Glyph-iOS.entitlements`, which holds only `com.apple.developer.kernel.increased-memory-limit`.
- No changes under `Sources/VectorEngine` except `Package.swift`'s `platforms`.
- The Mac canvas must draw identically. Compare `GLYPH_SNAPSHOT_*` PNGs from before and after Task 1.
- Never commit the owner's images. Use synthetic fixtures (`scripts/make-samples.swift`, `Tests/.../SyntheticFixtures.swift`).
- CI builds iOS with `CODE_SIGNING_ALLOWED=NO`.

## Review Focus

- **A 48 MP HEIC from Photos** has EXIF orientation. It must appear upright, decoded through `InputImage.orientedImage` from the same bytes.
- **Opening a second image while a trace runs** cancels the old run, the same as the Mac's `open`.
- **Rotating the iPad or resizing it in Split View** keeps the trace fitted, because `fitScale` is reported on `layoutSubviews`.
- **An empty or non-image clipboard on Paste** shows the existing "doesn't contain an image" alert.
- **Sharing before a trace has finished** is disabled while `result == nil`.

**Interfaces:**
- Produces: `struct CanvasRenderer { var bounds: CGRect; var vector: ShapeRenderer.Prepared?; var original: CGImage?; var outputSize: CGSize; var zoom: Double?; var pan: CGSize; var split: Double; var dark: Bool; var accent: CGColor; var editor: CurveEditor?; var selectedChain: Int?; var hoveredChain: Int?; var curveTransform: CGAffineTransform }`, with `fitScale: Double`, `scale: Double`, `origin: CGPoint`, `viewTransform: CGAffineTransform` and `func draw(in ctx: CGContext)`. ### Task 2: Make the shared model and views platform-neutral

**Files:**
- Modify: `App/Sources/AppModel.swift`, `App/Sources/StyleSections.swift`, `App/Sources/CanvasView.swift`, `App/Sources/ContentView.swift`, `App/Sources/GlyphApp.swift`
- Create: `App/Sources/SVGDocument.swift`

**Interfaces:**
- Produces:
  - `AppModel.open(imageData: Data, name: String)`: decodes with orientation and keeps the `Data` for `reload()`. The pasted image is replaced by `sourceData: Data?`.
  - `AppModel.paste()`: `NSPasteboard` on macOS; `UIPasteboard.general.image`'s PNG data on iOS.
  - `AppModel.copySVG()`.
  - `AppModel.svgDocument: SVGDocument?`.
  - `AppModel.exportName: String` (`<source>.svg`).
  - `struct SVGDocument: FileDocument, Transferable` (`.svg`, UTF-8).
  - `InputImage.orientedImage(data:)` if it doesn't exist yet. It sits in the App target, not the engine, as an extension mirroring `orientedImage(contentsOf:)`. If the engine already exposes only the URL form, write the data form in the app with `CGImageSourceCreateWithData` and the same options.
  - On iOS, `original` is downsampled to a 4096 px long side.
- `saveSVG()` (NSSavePanel), `SelfSnapshot`, `.commands`, the Undo forwarding through `NSApp`, the edit controls in `CanvasView`, and `EmptyStateView`'s Mac text are all `#if os(macOS)`.
- `StyleSections.swift:205` converts colors with `Color.resolve(in: EnvironmentValues())` instead of `NSColor`.

### Task 3: iOS target, canvas and layout

**Files:**
- Modify: `Package.swift` (`.iOS(.v17)`), `App/project.yml`, `App/Sources/ContentView.swift`, `App/Sources/GlyphApp.swift`
- Create: `App/Sources/VectorCanvasIOS.swift`, `App/Sources/IOSToolbar.swift`, `App/Sources/CameraPicker.swift`, `App/Glyph-iOS.entitlements`

**Interfaces:**
- Consumes: `CanvasRenderer` (Task 1) and the `AppModel` API (Task 2).
- `project.yml`:
  - `supportedDestinations: [macOS, iOS]` and `deploymentTarget.iOS: "17.0"`.
  - Entitlements per SDK.
  - `INFOPLIST_KEY_NSCameraUsageDescription: "Glyph traces photos you take into vector art."`
  - `INFOPLIST_KEY_UILaunchScreen_Generation: YES`
  - all orientations for iPhone and iPad
  - `INFOPLIST_KEY_LSSupportsOpeningDocumentsInPlace: NO`
  - `TARGETED_DEVICE_FAMILY: "1,2"`
  - Use `SUPPORTS_MACCATALYST: NO`, and keep the macOS settings intact.
- `VectorCanvasIOS` (a `UIViewRepresentable`): pinch zooms around its center; a one-finger pan within 22 pt of the divider moves `split`; other one- or two-finger pans move `pan`; double-tap toggles fit/actual size; `fitScale` is reported from `layoutSubviews`.
- iOS `ContentView`: a `NavigationStack` with the canvas or empty state, `.inspector(isPresented:)` with `InspectorView` and `.presentationDetents([.medium, .large])`, and a toolbar holding:
  - Open menu: Photo Library, Take Photo, Choose File, Paste.
  - Style menu.
  - Inspector toggle.
  - Export menu: ShareLink, Save to Files, Copy SVG.
  - `.dropDestination(for: Data.self)` for image drops.
  - The inspector is open by default when `horizontalSizeClass == .regular`.
- Camera: wrap `UIImagePickerController(sourceType: .camera)` and hide "Take Photo" when the camera isn't available.
